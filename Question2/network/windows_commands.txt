CSI205TC Question 2 — Windows commands
=======================================

Run these in PowerShell after the GitHub Pages URL is live. Replace the URL only if GitHub shows a different final URL.

$site = "https://chenletian718.github.io"
Resolve-DnsName chenletian718.github.io | Tee-Object Question2/network/nslookup.txt
nslookup chenletian718.github.io | Tee-Object Question2/network/nslookup-classic.txt
ping chenletian718.github.io -n 20 | Tee-Object Question2/network/ping.txt
tracert -d chenletian718.github.io | Tee-Object Question2/network/tracert.txt
curl.exe -I $site | Tee-Object Question2/network/https-headers.txt

Record the date, time, network type (Wi-Fi or Ethernet), and whether a VPN was enabled. Do not replace timeouts with invented values; retain them and explain them in the report.
